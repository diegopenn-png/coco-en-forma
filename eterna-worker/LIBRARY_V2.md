## Respuestas y seguridad

El Worker usa una copia compilada del contenido también almacenado bajo este identificador en Supabase. Una tabla de alias evita recorrer todo el corpus en cada consulta. Reconoce peticiones completas y naturales como «Hola Eterna, ¿me puedes explicar el sistema solar, por favor?». Una cláusula adicional, tema ambiguo, respuesta libre no comprobable, imagen o preferencia de idioma no cubierta conserva el recorrido del tutor habitual. No se utiliza coincidencia aproximada para inventar una corrección.

Se mantienen los controles de acceso, autorización familiar, perfil, suscripción, seguridad y límites de uso. Tildes, signos, números, exponentes y unidades se preservan al comparar respuestas. Los protocolos no califican saludos, emociones o pausas como errores. Los datos de hora, fecha y perfil no se sirven desde un ejemplo fijo. La cordialidad no suplanta una relación humana ni un diagnóstico.

La revisión publicada de contexto `e40e3bbbd7d6ae464a9e17659cd8ae3d36245852` se conserva: se reconocen las plantillas exactas del cliente, se preservan las interrupciones y el estado cerrado, y se cede al tutor IA cuando corresponde sin arrastrar instrucciones obsoletas. Los indicadores `lib:v1:` conservan las identidades de las preguntas, aunque cambie la versión del contenido.
