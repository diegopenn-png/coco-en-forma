¿Qué es Conecta colores?

Conecta colores es un juego de lógica de Coco en Forma. Une cada pareja del mismo color sin cruzar los caminos ni cerrar el paso a las parejas que todavía quedan por conectar.

La primera unión no siempre es la mejor. Mira el tablero completo, localiza los pasos estrechos y decide qué color necesita más espacio. Si una ruta bloquea otra, vuelve atrás y busca una alternativa. La gracia está en pensar cómo encajan todas las conexiones.

Un paso cada vez

Cómo se juega

  1. Observa las parejas

    Localiza los extremos de cada color antes de dibujar. Fíjate especialmente en las zonas con menos espacio.

  2. Traza y comprueba

    Une una pareja y revisa si el resto conserva una salida. Puedes corregir el recorrido cuando lo necesites.

  3. Completa la misión

    Resuelve los tableros que te propone la partida. Las pistas pueden ayudarte cuando no ves cómo seguir.

Una idea para empezar. Antes de tocar la pantalla, elige el color con menos alternativas. Un recorrido corto puede ser malo si deja sin salida a los demás.

Un pequeño ejemplo

Dos parejas necesitan atravesar el centro. ¿Conviene unir primero la pareja que tiene varios caminos posibles?

Ver una forma de pensarlo

Prueba a reservar primero el paso más estrecho para la pareja que no tiene otra salida. Después busca una ruta exterior para la que sí puede rodear el tablero.

Ejemplo explicativo de esta guía; no es una partida ni genera puntos.

Preguntas frecuentes

¿Se pueden cruzar los caminos?

No. Cada pareja necesita una ruta que respete el espacio de las demás.

¿Hay pistas?

Sí. Úsalas para entender un paso difícil y después intenta resolver el resto por tu cuenta; pueden influir en la puntuación.

¿Cómo accedo a Conecta colores?

Entra con tu cuenta de Coco para acceder y conservar el progreso disponible en tu perfil. El botón de esta página te lleva al juego dentro de Coco.

¿Se puede usar en la web y en la PWA?

Sí. Puedes acceder desde el navegador o desde la aplicación web de Coco instalada en tu dispositivo. Para salas online y funciones de cuenta necesitas conexión.
