¿Qué es Memoria?

Memoria es el juego de parejas de Coco en Forma. Descubre las tarjetas, recuerda dónde está cada imagen y encuentra las parejas del tablero.

Las colecciones rotan entre temas como ciencia, naturaleza, arte, deportes, tecnología y aventura. Más que girar tarjetas muy deprisa, el reto consiste en guardar una pequeña referencia de cada descubrimiento: qué viste y en qué lugar estaba.

Un paso cada vez

Cómo se juega

  1. Descubre dos tarjetas

    Mira tanto la imagen como su posición. Si no forman pareja, aprovecha esa información para la siguiente elección.

  2. Recuerda lo que viste

    Relaciona cada tarjeta con una referencia sencilla: una esquina, una fila o una tarjeta cercana.

  3. Encuentra las parejas

    Cuando reconozcas una imagen, busca su compañera. Continúa hasta completar el tablero.

Una idea para empezar. Tras cada intento, dedica un instante a recordar las dos tarjetas que acabas de descubrir. Ese momento también forma parte del juego.

Has visto una estrella arriba a la izquierda. Dos turnos después aparece otra estrella. ¿Qué información necesitas recuperar?

Preguntas frecuentes

¿Siempre aparecen las mismas imágenes?

No. Coco utiliza colecciones rotatorias de varios temas.

¿Puedo jugar desde el móvil?

Sí. El juego se abre desde Coco en el navegador del móvil y también desde su aplicación web instalada.

¿Cómo accedo a Memoria?

Entra con tu cuenta de Coco para acceder y conservar el progreso disponible en tu perfil. El botón de esta página te lleva al juego dentro de Coco.

¿Se puede usar en la web y en la PWA?

Sí. Puedes acceder desde el navegador o desde la aplicación web de Coco instalada en tu dispositivo. Para salas online y funciones de cuenta necesitas conexión.
