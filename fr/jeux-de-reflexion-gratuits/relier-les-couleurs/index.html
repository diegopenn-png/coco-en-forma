Relier les couleurs

Trace un chemin entre les deux points de chaque couleur. Les chemins doivent rester séparés jusqu’à ce que toutes les paires soient reliées.

Conseil de jeu

Repère les passages étroits avant de tracer ton premier chemin. Si une couleur ne peut passer que par une seule case, garde-la libre.

Un petit défi à essayer

Les points bleus ne peuvent être reliés que par la case centrale. Le rouge peut passer par le centre ou par le bord. Par où faire passer le rouge ?

Voir l’explication

Par le bord. Si le rouge occupe la case centrale, il ne restera aucun passage pour le bleu.
