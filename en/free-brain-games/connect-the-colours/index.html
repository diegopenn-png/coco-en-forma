Connect the colours

Draw a path between each pair of matching colours. The paths share a board, so a route that works for one pair can cut off another.

Connect the colours

Playing tip

Look for a pair that must pass through a narrow gap. Reserve that gap before drawing a line for a colour with more room.

Try a small challenge

A red pair can go around the edge or through a gap in the centre. The blue pair can only use the gap. Where should the red line go?

Show the explanation

Take red around the edge and leave the gap for blue. That way both pairs can still connect.
